Ứng Dụng Điều Khiển / Truyền File Socket Client-Server (Remote Desktop)

Ứng dụng điều khiển máy tính từ xa Client - Server qua TCP/IP Socket. Hệ thống truyền phát luồng ảnh chụp màn hình desktop và điều phối sự kiện chuột, bàn phím theo thời gian thực.

C# .NET 8.0 // SOCKET TCP/IP BUFFER STREAM

Vai trò: Thiết kế kiến trúc Packet Protocol (Header Type, Length, Payload), lập trình ServerSocket bắt tay TCP trên cổng 5000, xử lý ThreadPool phía Server.

Điểm nổi bật: Xử lý đa kết nối đồng thời với Task.Run, nén dữ liệu DeflateStream giảm 40% dung lượng byte buffer, truyền phát màn hình 25–30 FPS với độ trễ thấp (< 60ms).

Vấn đề: Hiện tượng nghẽn luồng giao diện WinForms (Thread Blocking) và trôi/mất gói tin khi truyền nhận stream ảnh màn hình liên tục ở tần số cao.

Giải pháp: Tách biệt I/O Worker Thread và UI Thread thông qua cơ chế Invoke, áp dụng Header Length Framing cùng cơ chế bắt tay ACK kiểm tra tính toàn vẹn của mảng byte.

C# .NET 8.0 Socket TCP/IP Screen Capture Stream Custom Protocol Multithreading

Hệ Thống Máy Bán Nước Tự Động Thông Minh IoT (FreshVend)

Hệ thống backend quản lý và vận hành máy bán hàng tự động bằng Java Spring Boot 3 kết nối vi điều khiển ESP32 giả lập Wokwi. Tiếp nhận telemetry nhiệt độ/độ ẩm và kích hoạt Servo nhả hàng tự động.

JAVA SPRING BOOT 3 // ESP32 WOKWI SIMULATOR

Vai trò: Thiết kế Backend RESTful API với Spring Boot 3, mô hình hóa máy trạng thái đơn hàng (Order State Machine), tiếp nhận và kiểm định dữ liệu telemetry từ vi điều khiển ESP32.

Điểm nổi bật: Xử lý 100+ requests/sec với thời gian phản hồi API < 45ms (kiểm chứng trên Thunder Client 200 OK • 6.5ms), đồng bộ tức thời số lượng tồn kho và doanh thu.

Vấn đề: Mất đồng bộ trạng thái khi kết nối mạng vi điều khiển ESP32 bị rớt giữa chừng sau khi trừ tiền mà hàng chưa kịp nhả (Race Condition).

Giải pháp: Áp dụng mô hình Two-Phase State Machine (PENDING → DISPENSING → COMPLETED / REFUNDED) kết hợp Heartbeat ping định kỳ 3s và tự động hoàn tiền nếu cảm biến nhả hàng không xác nhận.

Java Spring Boot 3 ESP32 Wokwi IoT REST API Telemetry OOP Architecture Thunder Client

Hệ Thống Quản Lý Trung Tâm Thú Y (PetCare Vet Center)

Website phòng khám thú y toàn diện (Đề tài Nhóm 2 - UTH). Phân hệ quản lý hồ sơ thú cưng, đặt lịch khám dịch vụ, bệnh án y tế và kê đơn thuốc cho bác sĩ thú y.

PHP PDO MYSQL // CHUẨN HÓA 3NF & BẢO MẬT

Vai trò: Backend Developer 1 (TV2) phụ trách thiết kế CSDL MySQL 8.0 chuẩn 3NF (12 bảng), lập trình phân hệ Đặt lịch khám, Hồ sơ bệnh án thú cưng và Đơn thuốc.

Điểm nổi bật: 100% Prepared Statements qua PDO chống triệt để SQL Injection, Composite Index trên [appointment_date, doctor_id] giúp truy vấn tìm lịch trống đạt O(log N).

Vấn đề: Hiện tượng trùng lịch khám (Double-booking) khi 2 khách hàng cùng đặt 1 bác sĩ tại cùng khung giờ, và lỗ hổng IDOR làm lộ hồ sơ thú cưng của chủ nuôi khác khi đổi ID trên URL.

Giải pháp: Sử dụng Transaction ACID với khóa SELECT ... FOR UPDATE chặn trùng lịch ở tầng CSDL/Server; kiểm tra nghiêm ngặt owner_id == session.user_id trước khi truy xuất dữ liệu bệnh án.
